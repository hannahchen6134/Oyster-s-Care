蚵仔照護指南

今天

照著順序做，就不會漏掉

每完成一項就按「完成」。如果蚵仔太抗拒，安全最重要，不用勉強餵藥或餵水。

0／7 今天的主要項目

今日時間表

罐罐不用記錄時間，只要記錄今天餵了幾次。這裡只保留需要提醒的時間。

房間環境不能改 冷氣請一直開著，不要關掉。窗戶請保持關閉，不要打開。
蚵仔不能碰到這些東西 咖啡、巧克力、橘子、任何清潔劑、洗碗精、防曬乳等，都要蓋好並收到蚵仔碰不到的地方。
1

從郵箱拿鑰匙

到達時先做

  • 到指定的郵箱，找到裝鑰匙的信封。
  • 取出鑰匙，信封請保留好，不要丟掉。
  • 用鑰匙進入家中。
2

先看看蚵仔

確認沒有明顯異常

  • 蚵仔在家，可以正常走動。
  • 呼吸和平常一樣。
  • 沒有明顯嘔吐、拉肚子、流血或其他異常。
找不到蚵仔時，先看這四個地方
  1. 推車內
  2. 廁所內
  3. 浴缸內
  4. 紙箱內

看到異常時，請到「異常聯絡」用 LINE 留言給 Hanna。

3

今天的餵食

每次餵完就按一次＋

罐罐／肉類

每次約 35g
一天至少4次，視情況第5次。不用記錄時間。

0今天已餵／至少4次

乾乾

每次約 10g
一天約2次。

0今天已餵／約2次
先看：正確秤重方式
  1. 把食物秤放在平穩的桌面並開機。
  2. 放上要使用的空碗。
  3. 按「歸零／TARE」。
  4. 確認顯示 0 g，單位一定要是 g（克）。
  5. 再慢慢放入蚵仔的食物，秤到指定克數。
罐罐／肉類怎麼準備
  1. 秤出約 35g 的罐罐或肉類。
  2. 蚵仔的肉可以直接加入70°C熱水。
  3. 加水量尚待 Hanna 補充。
  4. 攪拌後等待降溫，確認不燙才給蚵仔吃。
  5. 冰箱內的食物，照護者都可以取用；熱水也可以使用。
小心熱水熱水最低溫是70°C。加完不能立刻餵，一定要先攪拌、等待降溫。
4

餵藥與餵水

蚵仔安全最重要，不要硬餵

待補資料：藥名、每次藥量與餵藥時間。這些數字不自行猜測。
請看蚵仔的抗拒狀況 如果蚵仔抗拒太嚴重，沒有餵到水或藥沒關係，請立即停止。不確定藥有沒有吞下去時，不要自行再補餵一次。
  • 輕輕嘗試，從嘴巴側邊慢慢餵。
  • 餵水使用 3 ml小針筒。
  • 每次餵完藥後，看針筒剩多少，並憑感覺扣除大概流掉的水量。
  • 把蚵仔實際喝下的水量以「約幾 ml」記錄在喵喵照護管家。
  • 如果激烈掙扎、咳嗽、嗆到或呼吸異常，立刻停止。
  • 沒有成功時，在喵喵照護管家記錄即可。
5

每天離開前鏟貓砂

離開前一次，並查看尿尿與便便

  • 鏟掉尿塊與便便，依指定方式丟棄。
  • 確認今天有沒有看到尿尿與便便。
  • 有異常可用 LINE 留言給 Hanna。
6

離開前全部確認

益生菌、食物、飲水與房間安全

先餵益生菌

  1. 取益生菌 半包。
  2. 加入約 9ml 常溫礦泉水。
  3. 攪拌均勻，用約3支3 ml小針筒慢慢餵。
  4. 只能使用常溫礦泉水，不要用熱水。
  5. 若蚵仔太抗拒，立即停止，不用勉強餵完。

再逐項勾選

7

鎖門並放回鑰匙

一定要先鎖門，再放回郵箱

  1. 帶著鑰匙離開家門。
  2. 用鑰匙鎖好大門，拉一下確認真的鎖好了。
  3. 把鑰匙放回原本的信封並包好。
  4. 把信封放回原本的郵箱，關好郵箱。
不要把鑰匙帶回家不要放到其他郵箱。一定要先鎖好大門，再把鑰匙放回郵箱。
